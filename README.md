## 🚀 Side projects

### [meuquarto](https://github.com/LeandroTorres26/meuquarto)
A link-in-bio for media taste: one public profile showing the films, series, anime, manga, books, games, and music someone loves, synced from the platforms they already use (Letterboxd, AniList, Last.fm, Steam, Goodreads) or picked by hand. Java 21 and Spring Boot 4 API with PostgreSQL, Next.js 16 front end, Docker Compose, and documented architecture decisions (ADRs). Started as a university project, built to scale beyond it.

### [Easy Upload](https://github.com/LeandroTorres26/Easy-Upload)
Chromium extension, published on the Chrome Web Store, that replaces the system file picker on upload fields with your clipboard and most recent downloads, so a file is attached in one click. Filters by what the field accepts, supports multiple files, works inside iframes and modals, and has light/dark themes and PT/EN support. Vanilla HTML, CSS, and JavaScript, no dependencies, and no data ever leaves the browser.

### [My Media Catalogue](https://github.com/LeandroTorres26/my-media-catalogue)
Full-stack catalogue to track movies, TV shows, anime, and documentaries: status, season and episode progress, and ratings. Next.js 15, React 19, Zustand, MongoDB with Mongoose, NextAuth.js, and Vitest. TMDB auto-fills the form, and a provider-agnostic AI layer (Gemini, Groq, or Ollama) only suggests what TMDB can't cover, like anime subgenres.

### [Smart Recipe](https://github.com/LeandroTorres26/Smart-Recipe)
Recipe generator powered by Google Gemini. Built with Vue and TypeScript. Explored prompt engineering, API integration, and frontend state management for AI responses.
